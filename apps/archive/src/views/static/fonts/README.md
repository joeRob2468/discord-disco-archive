# Fonts

The archive is set in Satoshi by Indian Type Foundry, from [Fontshare](https://www.fontshare.com/fonts/satoshi), under the ITF Free Font License ([Satoshi-LICENSE.txt](Satoshi-LICENSE.txt)), not this project's MIT license.

The license allows self-hosting it for your own site, unmodified (no subsetting or converting), but not redistributing it, so the font file isn't in this repository (`.gitignore` keeps it out). To use it, download Satoshi from Fontshare and put `Fonts/WEB/fonts/Satoshi-Variable.woff2` from the download here, in this folder, before building or running the archive: on the server, copy it into this folder of the checkout. Without it, pages fall back to the system font.
